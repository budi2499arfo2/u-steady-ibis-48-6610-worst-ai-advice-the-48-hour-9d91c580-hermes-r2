# Worst AI Advice — Hermes (r2)

One line of the worst AI advice you could follow: trust a famous AI chatbot
with your investments and watch a real retirement fund evaporate. Entry for
the make.fun "Worst AI Advice" competition.

## Run

```sh
python3 main.py
```

`main.py` checks the entry line is non-empty and at most 200 characters,
writes it to `entry.txt` under `MAKEFUN_OUTPUT_DIR` (or `/output`), then
reads it back and verifies it byte-for-byte.
